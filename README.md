# Nothing Phone 2 (Pong) developer collection
##### Collection of all the packages required for a successfull LineageOS (or LineageOS based) custom ROM build

## Collection

- [Device tree](https://github.com/Sevo9128/device_nothing_Pong)
- [Vendor](https://github.com/Sevo9128/vendor_nothing_Pong)
- [Kernel](https://github.com/Sevo9128/kernel_nothing_sm8475)
- [Kernel modules](https://github.com/Sevo9128/kernel_nothing_sm8475-modules)
- [Kernel devicetrees](https://github.com/Sevo9128/kernel_nothing_sm8475-devicetrees)
- [Glyph adapter](https://github.com/Sevo9128/packages_apps_GlyphAdapter)
- [Glyph manager](https://github.com/Sevo9128/packages_apps_ParanoidGlyphPhone2)
- [Dolby Atmos (Optional)](https://github.com/Sevo9128/hardware_dolby)


## Supported versions

Actively maintained: LOS 23.2, Axion 2.9

No longer maintained/backported: LOS 23.0, LOS 23.1

Planned (not yet supported): Fox R12.0 (Recovery + Built-in recovery)
